# Jogo da Cobrinha (Snake)

## Descrição
Este é um jogo da cobrinha simples desenvolvido com **HTML5 Canvas**, **JavaScript puro** (sem bibliotecas externas) e **CSS**.  
- **Funciona offline**: basta abrir o `index.html` em qualquer navegador móvel (Android) que não precise de conexão com a internet.  
- **Controles**: teclado (setas ou WASD) e toque (deslize na tela).  
- **Tela responsiva**: o canvas se adapta a diferentes tamanhos de dispositivos Android.

## Requisitos
===
- Navegador que suporte **HTML5 Canvas** e **JavaScript** (Chrome, Firefox, Edge, Safari, etc.).  
- **Sem necessidade de conexão à internet** – todos os recursos são locais (HTML, CSS e JS).  
- **Sem dependências externas** – o código usa apenas o padrão do JavaScript (ECMAScript 2022) e o objeto `CanvasRenderingContext2D`.

## Como jogar
1. **Abra o arquivo `index.html`** no navegador do seu celular (Android).  
2. **Inicie o jogo**: o jogo já começa ao carregar a página.  
3. **Controle da cobra**:  
   - **Teclado** (ou teclado virtual): use as **setas** do teclado ou as teclas **W, A, S, D**.  
   - **Toque**: deslize o dedo na direção que deseja mover a cobra (para cima, baixo, esquerda ou direita).
